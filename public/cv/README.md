# Public CV downloads

These PDFs are generated from `scripts/generate_cv_pdfs.py` and served by Cloudflare Pages/Vite from this `public/cv` directory.

- `Marina_Ravliuk_CV_UA.pdf`: Ukrainian
- `Marina_Ravliuk_CV_EN.pdf`: English
- `Marina_Ravliuk_CV_IT.pdf`: Italian

The portfolio displays UA / EN / IT download controls in My Journey. To update a CV, edit its facts/translations in the generator and regenerate all three PDFs. Avoid disclosing private subscriptions, account identifiers or other non-public details.
